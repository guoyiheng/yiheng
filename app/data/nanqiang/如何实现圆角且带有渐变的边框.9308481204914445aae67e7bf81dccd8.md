## 问题：border-image 会导致设置的 border-radius 失效

原因如下：

![Untitled](%E5%A6%82%E4%BD%95%E5%AE%9E%E7%8E%B0%E5%9C%86%E8%A7%92%E4%B8%94%E5%B8%A6%E6%9C%89%E6%B8%90%E5%8F%98%E7%9A%84%E8%BE%B9%E6%A1%86/Untitled%202.png)

此问题会导致绘制出来的渐变边框没有圆角。

## 解决方案：可使用 clip-path 属性剪裁掉多余的部分

示例：

```
    border: 2rpx solid;
    border-image: linear-gradient(
        180deg,
        rgba(255, 255, 255, 1),
        rgba(255, 255, 255, 0)
      )
      2 2;
    border-radius: 16rpx;
    // !clip path to fix border-radius bug because of border-image
    clip-path: inset(0 round 16rpx);

```

属性具体信息：[clip-path──MDN](https://developer.mozilla.org/zh-CN/docs/Web/CSS/clip-path)
