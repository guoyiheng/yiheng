# 你在遗憾什么？

大概小学。

家里收粮食，地里有场面，我看场。

太无聊了，只有我一个人，大晚上的连虫子都有虫子陪着卿卿我我。

于是我拿出我宇宙无敌打字超快非智能按键手机，打开智能拼图，果断选择困难。

历时 1 个小时多，我趴在小屋被子上，拼完的时候感觉身体被掏空。

手机的清晰度图都看不清，拼到最后眼睛都快要使瞎。但我成功了，成功的那一刻我觉得自己无比变态。

我站起来大喊：我真 TM 牛逼。

<br/>

没有回应，连回声都没。

我站在那里，忽然感觉有点遗憾。而我遗憾什么，我也不知道。

<br/>

21 了，当初如果早恋估计孩子都有了。

游戏从红白机到街机到电脑了，可是依然不知道遗憾什么。

有些地方只去过一次，很想再去看一眼可是没机会了。

有些话只说过一次，很想再说一遍可是没来得及。

太懒了妈的，吃饭和拉屎都能同时进行。

<br/>

我讨厌过年，本想总应有一些开心吧。可半醒半梦中，翻过身后，满脸愁容。

炮竹一时间什么话都来不及讲，遗憾就已经铺满了一地的红妆。

这么多年来的菜米油盐也抵不过一段悲伤。

<br/>

酒大抵也解决不了。

<br/>
太多了，喜欢的得不到，坚持的意义不明，想做的心血来潮。

而我遗憾什么，我也不知道。
