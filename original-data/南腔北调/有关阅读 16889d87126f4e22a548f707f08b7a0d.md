# 关于kindle

我大概是大学时候买的第一台kindle。

那之后我阅读基本都是在kindle上进行的，偶尔也会看纸质书，一些好的书籍也会买来纸质的，或者技术类是会买纸质书来看。

**深度使用**了之后，我发现kindle问题非常多，多到会影响基本的使用。

**几个名词解释**

1. 标注
    
    比如这样一段文章：
    
    > 在我自己，本以为现在是已经并非一个切迫而不能已于言的人了，但或者也还未能忘怀于当日自己的寂寞的悲哀罢，所以有时候仍不免呐喊几声，聊以慰藉那在寂寞里奔驰的猛士，使他不惮于前驱。至于我的喊声是勇猛或是悲哀，是可憎或是可笑，那倒是不暇顾及的；但既然是呐喊，则当然须听将令的了，所以我往往不恤委婉了一点，在《药》的瑜儿的坟上平空添上一个花环，在《明天》里也不叙单四嫂子竟没有做到看见儿子的梦，因为那时的主将是不主张消极的。至于自己，却也并不愿将自以为苦的寂寞，再来传染给也如我那年青时候似的正做着好梦的青年。
    > 
    
    上面粉色背景标记的一句话，称为标注。
    
2. 笔记
    
    在标注的地方，可以选择输入一段思考或想法，作为笔记，笔记不显示在书籍中，会在标注右上角显示一个图标，点击图标或在菜单中可查看详细内容。
    
3. 个人文档
    
    除了在亚马逊官网购买的书籍资料，通过其他手段（USB连接电脑导入书籍文档，邮件发送到自己的kindle邮箱）导入的内容（书籍，文档，漫画），被亚马逊统一称为个人文档。
    

**细数kindle系统的罪行**

1. kindle的书籍存放逻辑
    
    可能是亚马逊觉得用户就是买书就看，不需要像纸质书买来还要考虑摆放书架哪里的问题，早期的整理书籍方式怪的离谱，而我又是个强迫症，非要给每个书籍都放在不同的文件中，尽管kindle有搜索功能，而**收藏夹在云同步的时候经会出现冲突问题**。
    
2. 标注问题
    
    看书的时候大家往往会经常标注一些句子，或者做一些笔记。而kindle在正版书籍的标注上，会有限制：**导出的内容长度不超过书籍的10%**，理由是为了正版内容保护。这时候往往我会导入一些盗版书籍作为“个人文档”来看（因为个人文档的标注所产生的MyClipping文件可以通过USB导出），这会引入另外一个问题：**kindle不支持个人文档的标记或笔记导出。**也就是说你自己导入或者发送到kindle的书籍，kindle禁用了导出功能，这个目的我就不清楚理由了，我自己的个人文档或者是盗版书籍导入到kindle上阅读之后，它不允许我导出自己的标注或笔记！匪夷所思。！
    
3. 还是标注问题
    
    后来我发现**kindle的标注会写在存储的一个MyClipping文件中**，只不过存储的内容杂乱无章。于是我用了几个周末写了一个解析和整理标注的网页，用来导出个人文档的标注和笔记，因为后面亚马逊退出了iphone和ipad的app，网页后续也无疾而终。后来很长一段时间之后，在我找一些新的导出笔记方法的时候，发现市面上的几个收费服务，我要是再更新更新也没啥太大的区别（失去发财机会）。
    
4. 继续标注问题
    
    iphone和ipad版本的app很好用，因为可以导出标注了。并且多端（kindle，iphone，ipad，mac）的标注可以同步了，并且最最最重要的，iphone和ipad的个人文档的标注，可以导出了。换句话说，**你在kindle上看的个人文档（比如盗版书籍），标注和笔记会同步在iPhone和ipad端，也就可以导出了**，曲线救国，喜大普奔！然而，奇怪的东西来了，多端同步，做的也跟屎一样。
    

**kindle多端同步的问题**

1. **mac端的app问题**
    
    多端同步，顾名思义，每个终端的内容应该都是一样的内容。可奇怪的是，iphone和ipad使用起来同步没有问题，**并且iphone和ipad可以导出个人标注**（赞）。奇怪的是**mac版本不显示个人文档**！只显示在亚马逊买的书籍，也就是说mac版本的kindle app，没法同步观看你在其他终端看的内容！在我向开发人员咨询确认了之后版本也不会加入这个功能之后，我截了图留了证据，以便为了以后加入这个功能的时候去嘲讽他们。我大意了，没想到2021年了，依然真没有这个功能。我就非常疑惑，这个这么基础的功能，为什么不做呢？这不是功能缺失这么简单的事情，而是内容缺失！是用户的内容没有显示完整！在其他端上都有的用户的资料、文件，mac的app上面没有，不奇怪吗？从技术的角度上分析，多端应该也是对接的同一套基础服务呀，虽然接口不尽相同，但是底层的数据理应是同一套，为何特殊处理mac端的返回数据呢，匪夷所思！
    
2. 同步的书籍显示和收藏夹显示问题
    
    正常来说，**同步的多个终端的书籍和多个收藏夹内容，不是一致的**（排除kindle中通过特殊方式导入的没有经过亚马逊云端处理的书籍）。但结果不是这样，会有一些意料之外的显示问题。比如ipad上显示了10个收藏夹，kindle上显示了8个，但是整体的书籍数量是没有错误的，然后在kindle上没有显示出来的两个收藏夹中的书籍，会散乱的显示在收藏夹之外。怪！
    
3. 标注问题
    
    没错，又是标注问题，为什么我老是说标注问题呢？因为看一本书，**提炼的精华和笔记（当时的思考）才是阅读之后最值得保存的部分**。但就是这个最重要的功能（在我看来最重要的），问题频发。前面说过：
    
    1. **标注的内容导出有限制**
    2. **kindle本身不支持个人文档的标记或笔记导出**
    3. **iPhone和ipad端会同步kindle端的笔记，可以间接实现个人文档的标记或笔记导出**
    4. **kindle的标注会写在存储的一个MyClipping文件中**
    
    那么多端同步在标注上面又有什么新的问题呢？同步的内容显示不完整，**ipad和iphone时常会显示`Tap to view hightlight in the book`** （导出标注的时候也显示这句话，你就会懵逼不知道自己标注的是个啥） ，但是kindle上看时正常显示标注的内容（但是前文说过，kindle无法导出个人文档的标注），在我google了一圈没有找到任何有关的信息之后，在亚马逊官网找到了一个反馈问题：[In iOS app, the highlights in notebook doesn't work properly.](https://www.amazonforum.com/s/question/0D54P00007NPxTy/in-ios-app-the-highlights-in-notebook-doesnt-work-properly) 但并没有解决的方案我。然后我在百度上搜到了一篇相关的帖子，楼主在一个层中回复自己发现了问题在哪，那就是，**当你在iphone/ipad上标注时，你需要标记一整段内容，而不是一句话，iphone/ipad app才会正常显示标注的内容。**我试了，确实如此。也就是说，如果我需要标记一句话，我需要把整段都给选中了！（为了吃这碗醋才包了这顿饺子！WTF！）再联系上文，标注还有导出内容的限制，可以导出的内容大小更加雪上加霜。更重要的是，许久之后，当你想在标注的古文诗词中找些难懂的文字来装潢自己的朋友圈时，发现标注了一大段一大段的文字，甚至看了一遍都不知道当初是为了哪句话而标注的这段话。
    

**无关紧要的问题**

以上，都是一些会影响基本阅读的问题，还有一些无关紧要的比如：

- 壁纸：kindle只能使用默认的壁纸，可以通过刷多看系统来更换壁纸
- 背光：kindle几我忘了，我最开始买的那个，是没有背光的，且显示屏面并不是现在的平面
- 字体：可选字体太少，和壁纸差不多，容易审美疲劳
- pdf：显示效果太差，这也是为什么技术类的书籍我会选择在电脑上或者买纸质书看
- 其他：发送书籍到kindle、没有锁屏密码（目前版本已支持）、没有语音服务（已有）等都是边边角角的小问题，只是使用不佳，没有影响到阅读。
- 等等
    
    

让人不禁诧异，亚马逊作为全球最大的纸质书厂商，且kindle还无比畅销，怎么连个看书的系统都做不好。研发费用都用来开发硬件了？

我翻来覆去睡不着，终于在半梦半醒中悟得玄机！满脑子冒出来的都是“泡面盖”！

# 有kindle后推荐的阅读方式

然而，说了这么多，我依旧在2018kindle推出新版本的时候，预购了新版的kindle，还加购了梵高向日葵的外壳。因为阅读观感的体验，当时的kindle还是无可匹敌的。

如果你是一个经常阅读，体验过每天晚上躺在床上看几个小时手机或者平板上的微信读书，（几天之后眼睛肿胀流泪）那你应该知道为什么我会选择电纸书。

如果你喜欢阅读，那么我推荐你买一款电纸书来体验，毕竟可以二次使用，拿来盖泡面严丝合缝我试过。

如果你想知道现在电纸书如何选择？我不知道。

但如果你有了kindle，那以下的建议可以提升你的阅读体验：

1. **阅读设备：kindle。**
    
    毫无疑问，保护好你的眼睛！一些碎片化阅读可以使用手机，毕竟也是同步的。
    
2. 书籍来源选择
    
    **正常的书籍都推荐在亚马逊官网购买**（什么，还有不正常的书籍？）观看，大部分热门书籍都会有更好的排版和X-ray支持(官方名词，一个书中出现的人物/名词参考附录) 
    
    **冷门书籍或者正版会阉割内容的书籍**（我不能接受打码的艺术！）可以通过一些网站下载。推荐一个毛子的网站：[https://ru.dk1lib.org/](https://ru.dk1lib.org/) ，很多冷门的资源我都在这里找到的！
    
3. 书籍的导入（稍微需要一点动手的能力，也只是稍微，试一下很简单）
    
    **推荐邮件导入，**大致步骤：
    
    1. kindle设置中设置一个接收邮件的邮箱A
    2. 通过其他邮箱B发送邮件（附件书籍）到邮箱A
        
        注1：其他邮箱B需要在亚马逊官网→设备和内容中设置邮箱A可接收的邮箱白名单（不然别人岂不是可以随意发送书籍到你的kindle中）。
        
        注2：目前，发送之后，亚马逊会给邮箱B回复一封确认发送的邮件，点击确认即可。
        
        注3：邮件发送成功，正常会在5分钟内就会同步到你的kindle中（kindle需联网，可手动点击菜单同步）有问题自行百度
        
    
    通过USB连接电脑，直接将书籍拖到kindle设备中
    
    不推荐，原因是这种方式导入的书籍不会同步到其他设备中。（也就无法使用下面的标注导出功能）
    
4. 标注和笔记同步
    1. **亚马逊官网购买的书籍**可以自行在书籍阅读页面，找到标注和笔记，最下方是导出。
    2. 个人文档（我们自行下载的且不是通过USB导入的书籍），kindle阅读页面，标注和笔记下方，没有导出按扭。
        1. 第一种方式，不推荐。USB连接电脑找到**MyClipping.txt**文件，里面是你在kindle中所有书籍的标注
        2. 第二种方式，推荐。kindle联网，标注同步后，在其他终端kindle app（iphone/ipad）中，书籍页面，导出标注和笔记。（此方式导出的笔记和标注会有排版）
    3. 个人文档（通过USB导入的书籍）
        1. 只能通过上述第一种方式（USB连接电脑找到MyClipping.txt文件，里面是你在kindle中所有书籍的标注）
